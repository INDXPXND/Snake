# Snake Game

Классическая игра "Змейка" с механикой ускорения, написанная на Python с использованием Pygame.

## Особенности

- 🎮 Плавное управление с помощью стрелок
- ⚡ Ускорение при удержании клавиши в направлении движения
- 🍎 Яблоки дают очки и увеличивают змейку
- 🥔 Гнилой картофель отнимает очки

## Управление

- **Стрелки** - изменение направления
- **Удержание стрелки** в текущем направлении - ускорение
- **Пробел** - перезапуск после проигрыша

## Установка и запуск

### Запуск из исходного кода

1. Установите Python 3.8 или новее
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Запустите игру:
```bash
python main.py
```

### Компиляция в .exe
```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name "Snake Game" --hidden-import=pygame --icon=icon.ico snake_game.py
```

Готовый .exe файл будет в папке `dist/`
